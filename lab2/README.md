# Лабораторная работа 2. Виртуальный датчик печи обжига

По минутной телеметрии оценивается концентрация продукта в момент лабораторной пробы. Проба берётся не каждую минуту, ответ лаборатории приходит с задержкой, поэтому оператор видит показатель поздно.

## Данные

Файлы лежат рядом с ноутбуком.

- `data_train.csv` и `target_train.csv`, телеметрия и пробы для обучения, март-октябрь 2019
- `data_test_small.csv` и `target_test_small.csv`, кусок для проверки, октябрь-ноябрь 2019

В телеметрии 16 датчиков, шаг одна минута. В целевом файле нерегулярные замеры, обычно раз в два часа.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook lab2.ipynb
```

Ячейки нужно выполнять сверху вниз. Тестовая телеметрия склеивается с обучающей только для того, чтобы скользящие окна на стыке периодов видели недавнюю историю. Целевые значения теста в обучение не попадают.

## Что получается

Ориентир без модели, повторяем предыдущую пробу. На тесте у неё MAE 0.059 и RMSE 0.080, направление изменения угадывается примерно в 37% шагов.

Гребневая регрессия на тех же пробах даёт MAE 0.051 и RMSE 0.067, направление около 48%. Бустинг почти такой же, лес чуть хуже. Считаются модели за секунду.

Главный признак здесь прошлая проба. Из телеметрии заметны датчик 0 и последняя отметка датчика 15. Сдвиг ровно на 10-15 минут линейную связь почти не усиливает.

Датчик полезен как подсказка между пробами, лабораторию он не заменяет. Около половины шагов направление всё ещё другое, остатки не нормальны, разброс ошибки неровный.
