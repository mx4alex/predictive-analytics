# Лабораторная работа 3. Климат и прогноз температуры по шести городам

По окну погоды за 30 суток называем тип климата, а затем для этого климата считаем температуру на каждый день следующего месяца.

## Данные

Файлы лежат в папке `data`, по одному parquet на город и год с 2019 по 2025. Города: Москва, Санкт-Петербург, Сочи, Геленджик, Благовещенск и Находка. В файле шаг один час, а в ноутбуке ряд сведён к суткам.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook lab3.ipynb
```

Ячейки нужно выполнять сверху вниз. Норму календарного дня считаем только по 2019-2023, по 2024 выбираем формулу, а 2025 оставляем для проверки.

## Что получается

На 2025 климат по окну в 30 суток узнаётся с accuracy 0.748 и F1 macro 0.749. Зимой доля верных 0.881, летом 0.590. Санкт-Петербург часто называют Москвой, а Сочи узнаётся лучше.

Температуру на сутки вперёд лучше всего даёт гребневая регрессия на отклонении от нормы, MAE от 1.158 в Сочи до 1.713 в Благовещенске. На 30 суток вперёд у всех городов остаётся норма календарного дня, MAE от 2.387 в Находке до 3.923 в Москве. Ошибка названия климата на сутках добавляет около 0.025 градуса, а месячный прогноз идёт по норме самого города.
